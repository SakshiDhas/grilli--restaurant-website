# 🍴 Restaurant Website

A simple and responsive restaurant website built with **HTML, CSS, and JavaScript**.  
It includes multiple sections such as **Home, Menu, About Us, Our Chefs, and Contact** to provide a complete restaurant experience online.

---

## 🚀 Features
- Responsive design for desktop and mobile devices  
- Navigation bar with smooth scrolling to different sections  
- Stylish Menu section showcasing food items  
- About Us page to describe the restaurant’s story  
- Our Chefs section highlighting the team  
- Contact form for user inquiries  

---

## 🛠️ Technologies Used
- **HTML5** – Structure of the website  
- **CSS3** – Styling and layout (responsive design)  
- **JavaScript** – Interactivity and dynamic features
